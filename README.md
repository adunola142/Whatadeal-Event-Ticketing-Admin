# Whatadeal Admin Dashboard

Admin dashboard for managing organizations, events, POS sales, and payouts on the Whatadeal ticketing platform.

## Development

You need Node.js and npm (or bun) installed.

```sh
git clone <this-repository-url>
cd Whatadeal-admin
bun install
bun run dev
```

## Tech Stack

- **React 19** with TypeScript
- **TanStack Router** + **TanStack Start** (SSR)
- **Tailwind CSS 4**
- **Vite 8**
- **Radix UI** components
- **Recharts** for data visualization

## Scripts

- `bun run dev` — Start dev server
- `bun run build` — Production build
- `bun run preview` — Preview production build
- `bun run lint` — Run ESLint
- `bun run test` — Run tests
